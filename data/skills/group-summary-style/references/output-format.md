# 输出格式规范

本文件是 `群聊总结风格` 技能的补充说明，仅在需要严格对齐输出格式时读取。

## 长度

- 总长度控制在 300-800 字
- 单个维度不超过 200 字
- 话题标题不超过 15 字

## 分段

每个维度用二级标题，维度之间空一行：

```
## 热门话题

（内容）

## 有效信息

（内容）
```

## emoji

- 每个维度标题前可加一个 emoji，全篇不超过 4 个
- 正文内不使用 emoji
- 若群内风格严肃（如工作群），全篇不使用 emoji

## 引用发言

格式为 `群名片：观点`，不加引号：

```
张三：认为方案 A 的成本更低
```

多人同意同一观点时合并：

```
张三、李四：都倾向方案 A
```

## 链接

保留原始 URL，不要缩短或改写。若同一链接被多次分享，只列一次。

## 时间

涉及时间时用相对表述（"今天下午"、"昨晚"），除非原文给了具体日期。
